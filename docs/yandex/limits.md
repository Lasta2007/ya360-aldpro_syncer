# Ограничения

При работе с API действуют следующие ограничения:

- Запросы могут выполняться только от имени [администратора](https://yandex.ru/support/yandex-360/business/admin/ru/organization/admin) организации.
- С помощью API можно управлять не более чем 500 организациями от имени одного пользователя.
